# 用例清单

用途：把「用例编号 ↔ 中文名 ↔ py 文件」对在一起，方便查找、评审和追溯。**表格由代码生成，不手写**——手写的副本一定会和代码漂移（本项目已经踩过：设计文档用 `ST-BAG-API-007`，代码用 `-heal`/`-cap`）。

维护方式：

- 表格（下面带 `generated` 标记的那段）：`python scripts/case_table.py` 重写
- 过期自检：`python scripts/case_table.py --check`（不一致返回 1）
- 中文名的**唯一来源**是用例的 marker：`@pytest.mark.case(id=…, game=…, module=…, kind=…, title="买两个奶酪：金币100→60、背包+2")`
  —— `title` 可选，未填时表格显示「（待补）」并计入末尾的待补条数

权威计数与筛选入口仍是 `pytest cases --collect-only`；已设计但未实现的条目见 `docs/功能用例目录.md` 与可视化面板的「用例清单」页（本表只列已实现用例，避免再复制一份设计资料）。

**本表不含运行状态**：某条用例最近跑成什么样是会变的状态，放在 `reports/` 与面板的「结果」页。如果写进这张要提交的文档，每跑一次测试它就"过期"，`--check` 也就没人看了。
